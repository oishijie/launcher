# Launcher — Windows 快速启动器

把常用程序、文件夹、网页**拖进网格**，一键（点一下 / 按个键 / 全局热键）打开。极简、纯原生、便携：.NET Framework 4.7.2 / WinForms，无第三方依赖，无安装包。

- 原项目（上游）：[cornradio/launcher](https://github.com/cornradio/launcher)
- 软件简介（中文，小众软件论坛）：https://meta.appinn.net/t/topic/67580
- 本项目（下游维护）：[worldoi/launcher](https://github.com/worldoi/launcher)
- 版本：1.0.0

| 能力 | 说明 |
|------|------|

## 安装与启动

**便携版（推荐）** 下载 `launcher-portable.zip` 解压即可运行 `launcher.exe`——无需安装、无需管理员权限。

**运行环境**：Windows 7 SP1+ / 8 / 10 / 11，需 .NET Framework 4.7.2 或更高（Win10/11 自带）。

数据文件（首次运行自动生成，全部在程序目录）：

| 文件 | 作用 |
|------|------|
| `launcher.json` | 主配置：布局 / 主题 / 快捷键 / 各页槽位数据 |
| `notes.txt` | 便签内容（UTF-8 纯文本，可手动编辑） |
| `launcher.log` | 运行日志（异常诊断用） |
| `backups/` | 导入前自动备份的配置包（自动生成） |
| `icons/` | 从备份/导入还原的自定义图标（自动生成） |

> 建议：升级版本时把旧目录的 `launcher.json`、`notes.txt` 复制过去即可保留配置与便签。

## 基本使用

### 添加条目

- **程序 / 文件**：从资源管理器**直接拖入**槽位。
- **快捷方式（.lnk）**：一样拖入，自动解析并显示目标程序图标；`.bat` `.txt` `.rdp` `.zip` 等任意文件均可。
- **网页链接**：拖入 http/https 网址（或复制链接后拖入），自动画「地球」图标，点击用默认浏览器打开。
- **设置自定义图标**：右键槽位 →「设置自定义图标…」（png/jpg/ico/bmp）。

### 打开与操作

- **左键单击**：打开程序 / 文件夹 / 链接（双击也只会开一个实例）。
- **中键**：打开该程序的所在位置（文件管理器）。
- **右键**：上下文菜单——设置/清除自定义图标、删除（`Ctrl+Z` 可撤销误删）。

### 拖拽排序

拖动一个图标到另一个槽位即可交换位置——悬停目标时显示**虚线落点框 + 呼吸高亮**、源图标淡化，松手才真正换位，防止误放。

### 隐藏 / 唤出

点主面板外部自动隐藏（可配置关闭）；`Ctrl+`` ` 全局热键随时唤回；托盘图标同理。

**双击桌面空白处或任务栏空白位置**也能直接呼出面板（默认开启，可在 `launcher.json` 的 `layout.dblClickShow` 设为 `false` 关闭）。

## 搜索

主面板顶部的搜索框**跨页搜索**所有页面的条目：

- 输入即过滤（文件名 / 路径 / URL 包含匹配）；**所有页的匹配项合并显示**（最多 40 个），其余槽位隐藏，分页圆点自动收起。
- 键盘：`Enter` 打开首个（或选中的）匹配；`↑ ↓` 移动选中（当前选中项带高亮环）；`Esc` 清除搜索。
- 搜索框聚焦时数字键 1-9 直接打开第 N 个匹配。
- 呼出面板时自动聚焦搜索框；再次呼出自动清空搜索、恢复原始页面。

## 分页与重命名

底部圆点 = 页面：

- **翻页**：点击圆点，或 A / D 键。
- **新增页**：托盘菜单「新增一页(&P)」——页数 +1 并跳转到新空白页（上限 20 页）。
- **删除页**：「删除当前页(&D)」——后续页自动前移；非空页二次确认防误删（至少保留 1 页）。
- **重命名**：右键圆点或托盘「重命名当前页(&R)」，页面名会显示在圆点悬停提示里，并在 `launcher.json` 持久化。

## 便签面板（支持 Markdown）

托盘「便签面板」或全局热键 `Ctrl+Shift+N` 呼出：

- **即写即存**：输入即自动保存到 `notes.txt`（无保存按钮）。
- **Markdown 预览**：点便签右上角「预览」按钮切换——支持 `#` 一级标题～六级、`**粗体**`、`*斜体*`、`` `行内代码` ``、`- / * / +` 列表、`[文字](链接)`；预览中的链接可直接点击打开，且随深浅主题配色切换。
- `notes.txt` 存的是纯 Markdown 源文本，可放心用记事本等直接编辑。

## 自定义图标

- 右键槽位 →「设置自定义图标…」（png/jpg/ico/bmp）。
- 「清除自定义图标」恢复为系统图标。
- 导出/导入配置时自定义图标**自动打包**进 `icons/`，换机不丢图。
- 未设自定义图标时：程序/文件夹取系统图标，网页取地球字形。

## 主题

标题栏「🌓」按钮或热键 `Ctrl+Shift+T`（或托盘菜单）切换深色/浅色皮肤；选择会写入 `launcher.json` 并在下次启动保留。

## 全局热键

| 默认 | 功能 | 配置键（`hotkeys` 段） |
|------|------|------|
| `Ctrl+`` ` | 呼出/隐藏主面板 | `main` |
| `Ctrl+Shift+N` | 呼出/隐藏便签 | `notes` |
| `Ctrl+Shift+T` | 切换深浅色主题 | `theme` |
| `Ctrl+Z` | 撤销误删 | `undo` |
| A / D | 上一页 / 下一页 | `prevPage` / `nextPage` |

> 热键均可自定义。如果 `Ctrl+``（反引号，数字 1 左侧）或 `Win+Space` 被系统/其他软件占用，可在 `launcher.json` 的 `hotkeys` 段改成 `Alt+~` 之类。监听不到时排查热键冲突软件。

## 配置：launcher.json

`launcher.json` 结构（首次运行自动生成；改完保存即热生效，无需重启）：

```jsonc
{
  "version": 1,
  "layout": {
    "slotCount": 40,     // 每页槽位数（1~400）
    "iconSize": 54,      // 图标尺寸（16~256）
    "pageCount": 4,      // 页数（1~20）
    "columns": 8,        // 列数（1~40）
    "width": 0,          // 窗口宽(像素)：0=自动；也可直接拖动窗口边缘调整后自动写回
    "height": 0,         // 窗口高(像素)：0=自动
    "autoHide": true     // 点外部自动隐藏（去掉即可，或 false 关闭）
  },
  "theme": "Dark",       // Dark / Light
  "lastPage": "第1页",
  "hotkeys": { "main": "Ctrl+`", /* ... 见上表 ... */ },
  "pages": [
    {
      "name": "第2页",
      "slots": [
        { "index": 0, "path": "C:\\...\\xxx.exe", "isFolder": false, "icon": "" }
      ]
    }
  ]
}
```

> `path` 支持绝对路径 `C:\...`、UNC、`.lnk` 快捷方式和 `http(s)://` 链接。

## 备份 / 导出 / 导入

**导出配置**：托盘菜单「导出配置…」→ 生成 zip，打包 `launcher.json` + `notes.txt` + `launcher.ini` + `icons/` 下的自定义图标，换机/重装直接还原。

**导入配置**：托盘菜单「导入配置…」选择 zip 还原；**导入前自动把当前配置备份到 `backups/` 目录**（时间戳 zip），万一导入出错可直接回滚。

## 项目结构

```
├─ Controls/     # UI 层：Form1（主窗体力）、IconSlot（槽位控件）、PageIndicator（分页圆点）、IconRenderer（图标渲染）、PageNameDialog、AboutForm
├─ Core/         # 逻辑层（无 UI 依赖、可单测）：ConfigStore（配置/持久化）、SearchEngine（搜索）、KeyRouter（快捷键路由）、ConfigExporter（导出）、MarkdownRenderer（markdown→RTF）、ThemePalette、HotkeyBinding、Program
├─ Models/       # SlotData 等数据模型（DataContract 序列化）
├─ tests/        # MSTest 测试集
└─ publish/      # 便携交付包（程序目录 + zip）
```

## 常见问题

- **Q：拖入后图标是默认文件夹图标？**
  A：表示该文件提取关联图标失败（个别绿色加密/自定义扩展名）。可右键「设置自定义图标…」指定任意 png/ico。

- **Q：`.lnk` 快捷方式打开之后图标是快捷方式的？**（`A`）不会，会自动解析成目标程序图标再提取。

- **Q：便签不怕丢？** 内容写入 `notes.txt`，掉电不丢；Markdown 源码即所见。

- **Q：为什么双击打不开？** 检查是否只运行了单实例（重复启动只会唤起已有窗口）；如仍是打开即消失，看程序目录 `launcher.log` 的错误信息。

- **Q：如何换主题？** 标题栏「🌓」按钮 / `Ctrl+Shift+T` / 托盘菜单，三者等价。
