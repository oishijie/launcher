# Launcher — Windows 快速启动器

把常用程序、文件夹、网页**拖进网格**，一键（点一下 / 按个键 / 全局热键）打开。极简、纯原生、便携：.NET Framework 4.7.2 / WinForms，无第三方依赖，无安装包。

- 原项目（上游）：[cornradio/launcher](https://github.com/cornradio/launcher)
- 软件简介（中文，小众软件论坛）：https://meta.appinn.net/t/topic/67580
- 本项目（下游维护）：[oishijie/launcher](https://github.com/oishijie/launcher)
- 版本：1.1.0（v1.1.0：界面全面重构为 Fluent 风格 + Everything 全盘搜索 + 便签独立窗口）

## 安装与启动

**便携版（推荐）** 下载 `launcher-portable.zip` 解压即可运行 `launcher.exe`——无需安装、无需管理员权限。

**运行环境**：Windows 7 SP1+ / 8 / 10 / 11，需 .NET Framework 4.7.2 或更高（Win10/11 自带）。

数据文件（首次运行自动生成，全部在程序目录）：

| 文件 | 作用 |
|------|------|
| `launcher.json` | 主配置：布局 / 主题 / 快捷键 / 各页槽位数据 |
| `notes/` | 多便签存储（每条一个 `.txt`，UTF-8 纯文本可手动编辑；旧版单文件 `notes.txt` 首次运行自动迁移） |
| `launcher.log` | 运行日志（异常诊断用） |
| `backups/` | 导入前自动备份的配置包（自动生成） |
| `icons/` | 从备份/导入还原的自定义图标（自动生成） |
| `everything/` | 捆绑的 Everything（voidtools）搜索组件，全盘搜索用；删除后自动降级到命令行模式，不影响其他功能 |

> 建议：升级版本时把旧目录的 `launcher.json`、`notes.txt` 复制过去即可保留配置与便签。

## 基本使用

### 添加条目

- **程序 / 文件**：从资源管理器**直接拖入**槽位。
- **快捷方式（.lnk）**：一样拖入，自动解析并显示目标程序图标；`.bat` `.txt` `.rdp` `.zip` 等任意文件均可。
- **网页链接**：拖入 http/https 网址（或复制链接后拖入），自动画「地球」图标，点击用默认浏览器打开。
- **设置自定义图标**：右键槽位 →「设置自定义图标…」（png/jpg/ico/bmp）。

### 打开与操作

- **左键单击**：打开程序 / 文件夹 / 链接（双击也只会开一个实例）。
- **中键**：打开该程序的所在位置（文件管理器）。
- **右键**：上下文菜单——设置/清除自定义图标、删除（`Ctrl+Z` 可撤销误删）。

### 拖拽排序

拖动一个图标到另一个槽位即可交换位置——悬停目标时显示**虚线落点框 + 呼吸高亮**、源图标淡化，松手才真正换位，防止误放。

### 隐藏 / 唤出

点主面板外部自动隐藏（可配置关闭）；`Ctrl+`` ` 全局热键随时唤回；托盘图标同理。

**双击桌面空白处或任务栏空白位置**也能直接呼出面板（默认开启，可在 `launcher.json` 的 `layout.dblClickShow` 设为 `false` 关闭）。

## 搜索

点击标题栏**放大镜图标**展开搜索框（`Esc` 或点击空白处收起），跨页搜索所有条目：

**本机图标匹配**（始终可用）

- 输入即过滤（文件名 / 路径 / URL 包含匹配）；**所有页的匹配项合并显示**（最多 40 个），其余槽位隐藏，分页圆点自动收起。
- 键盘：`Enter` 打开首个（或选中的）匹配；`↑ ↓` 移动选中（当前选中项带高亮环）；`Esc` 收起搜索框。
- 搜索框聚焦时数字键 1-9 直接打开第 N 个匹配。

**Everything 全盘匹配**（默认开启，设置面板可关）

本机图标之后会**自动追加**全盘文件名命中（最多 40 条，图标从文件现场提取），点一下即打开：

- 无需单独安装 Everything——程序目录 `everything\` 已捆绑完整组件，首次搜索自动拉起其后台服务并建立索引。
- 走 SDK 直查（`Everything64.dll`），响应毫秒级；SDK 不可用时自动降级到 `es.exe` 命令行，功能不受影响。
- 状态自检：设置面板 → 常规 → 「Everything 全盘搜索」行右侧**「检测」**按钮，实时显示链路状态与索引条数（如「就绪（SDK 模式）· 已索引 1,512,390 项」），可区分「未运行」「索引为空」「不可用（原因）」三类情况。
- 隐私说明：Everything 仅检索**文件名**，索引数据存于本机 `everything\` 目录，不上传任何数据。

## 分页与重命名

底部圆点 = 页面：

- **翻页**：点击圆点，或 A / D 键。
- **新增页**：托盘菜单「新增一页(&P)」——页数 +1 并跳转到新空白页（上限 20 页）。
- **删除页**：「删除当前页(&D)」——后续页自动前移；非空页二次确认防误删（至少保留 1 页）。
- **重命名**：右键圆点或托盘「重命名当前页(&R)」，页面名会显示在圆点悬停提示里，并在 `launcher.json` 持久化。

## 便签窗口（支持 Markdown）

标题栏便签图标或全局热键 `Ctrl+Shift+N` 呼出**独立窗口**（不随主面板隐藏，可分屏摆放）：

- **多便签**：左缘列表排列所有便签，点击切换；顶部「＋」新建，「×」删除当前便签（二次确认）。
- **即写即存**：输入即自动保存（无保存按钮），切换 / 关闭窗口不丢内容。
- **Markdown 预览**：点右上角「预览」按钮切换——支持 `#` 一级～六级标题、`**粗体**`、`*斜体*`、`` `行内代码` ``、`- / * / +` 列表、`[文字](链接)`、**管道表格**（表头底纹加粗、`:---:` 对齐、列宽按内容自适应）；预览中的链接可直接点击打开，随深浅主题配色切换。
- 每条便签存为 `notes/` 下的独立 `.txt`（纯 Markdown 源文本），可放心用记事本等直接编辑；旧版单文件 `notes.txt` 首次运行自动迁移。

## 自定义图标

- 右键槽位 →「设置自定义图标…」（png/jpg/ico/bmp）。
- 「清除自定义图标」恢复为系统图标。
- 导出/导入配置时自定义图标**自动打包**进 `icons/`，换机不丢图。
- 未设自定义图标时：程序/文件夹取系统图标，网页取地球字形。

## 主题

标题栏「🌓」按钮或热键 `Ctrl+Shift+T`（或设置面板）切换深色/浅色皮肤；选择会写入 `launcher.json` 并在下次启动保留。两套主题均为 Fluent 配色（四层色阶），全界面自绘控件 + 无边框圆角窗口，Win10/Win11 表现一致。

## 设置面板

标题栏「⚙」按钮或托盘菜单「设置」打开，所有开关集中管理、即时生效：

| 开关 | 说明 |
|------|------|
| 开机自启 | 当前用户注册表 Run 项，无需管理员 |
| 点外部自动隐藏 | 失焦隐藏主面板 |
| 贴边自动隐藏 | 窗口拖到屏幕边缘缩进（露出 12px），鼠标移到边缘停约半秒唤出；「置顶钉住」时不缩进 |
| 双击桌面呼出 | 双击桌面/任务栏空白处呼出面板 |
| Everything 全盘搜索 | 关闭后搜索仅匹配本机图标；右侧「检测」按钮自检链路状态 |
| 窗口透明度 | 90–100% 无级调节（低于 100% 时圆角由分层窗口绘制） |

其余（主题切换、分页增删改、导入导出）也都在设置面板里，托盘菜单只保留「显示/隐藏 · 设置 · 退出」三项。

## 贴边自动隐藏

窗口拖近屏幕边缘（≤18px）自动缩进到只露一条边；鼠标移到屏幕边缘停一下即缓出。右下角拖拽尺寸、置顶钉住状态下均不会误触发，可在设置面板随时关闭。

## 全局热键

| 默认 | 功能 | 配置键（`hotkeys` 段） |
|------|------|------|
| `Ctrl+`` ` | 呼出/隐藏主面板 | `main` |
| `Ctrl+Shift+N` | 呼出/隐藏便签 | `notes` |
| `Ctrl+Shift+T` | 切换深浅色主题 | `theme` |
| `Ctrl+Z` | 撤销误删 | `undo` |
| A / D | 上一页 / 下一页 | `prevPage` / `nextPage` |

> 热键均可自定义。如果 `Ctrl+``（反引号，数字 1 左侧）或 `Win+Space` 被系统/其他软件占用，可在 `launcher.json` 的 `hotkeys` 段改成 `Alt+~` 之类。监听不到时排查热键冲突软件。

## 配置：launcher.json

`launcher.json` 结构（首次运行自动生成；改完保存即热生效，无需重启）：

```jsonc
{
  "version": 1,
  "layout": {
    "slotCount": 40,           // 每页槽位数（1~400）
    "iconSize": 54,            // 图标尺寸（16~256）
    "pageCount": 4,            // 页数（1~20）
    "columns": 8,              // 列数（1~40）
    "width": 0,                // 窗口宽(像素)：0=自动；拖动窗口边缘调整后自动写回
    "height": 0,               // 窗口高(像素)：0=自动；手动设过高度后程序不再自动调整
    "autoHide": true,          // 点外部自动隐藏
    "opacity": 100,            // 窗口透明度（90~100）
    "edgeAutoHide": true,      // 贴边自动隐藏
    "everythingSearch": true   // Everything 全盘搜索
  },
  "theme": "Dark",       // Dark / Light
  "lastPage": "第1页",
  "hotkeys": { "main": "Ctrl+`", /* ... 见上表 ... */ },
  "pages": [
    {
      "name": "第2页",
      "slots": [
        { "index": 0, "path": "C:\\...\\xxx.exe", "isFolder": false, "icon": "" }
      ]
    }
  ]
}
```

> `path` 支持绝对路径 `C:\...`、UNC、`.lnk` 快捷方式和 `http(s)://` 链接。

## 备份 / 导出 / 导入

**导出配置**：托盘菜单「导出配置…」→ 生成 zip，打包 `launcher.json` + `notes.txt` + `launcher.ini` + `icons/` 下的自定义图标，换机/重装直接还原。

**导入配置**：托盘菜单「导入配置…」选择 zip 还原；**导入前自动把当前配置备份到 `backups/` 目录**（时间戳 zip），万一导入出错可直接回滚。

## 从源码构建

```
dotnet build launcher.csproj -c Release   # 产物 bin\Release\launcher.exe
dotnet test tests\Launcher.Tests -c Release  # 运行测试（53 项）
```

- 环境：.NET SDK（含 .NET Framework 4.7.2 targeting pack），Windows。
- 运行测试：`dotnet test tests\Launcher.Tests -c Release`。
- 工程已显式关闭 `Prefer32Bit`：产物为 AnyCPU（64 位系统上跑 64 位进程），`everything\Everything64.dll`（64 位原生库）可被直接 P/Invoke。若自行改回 32 位，全盘搜索会自动降级到 `es.exe` 命令行模式，其余功能不受影响。

## 项目结构

```
├─ Controls/     # UI 层：Form1（主窗体）、UiKit（自绘控件库：按钮/开关/列表/菜单/搜索框）、SettingsForm（设置面板）、NotesWindow（便签窗口）、IconSlot（槽位控件）、EdgeAutoHide（贴边隐藏）、PageIndicator（分页圆点）、IconRenderer（图标渲染）、CommandDialog / PageNameDialog（对话框）

├─ everything/   # 捆绑的 Everything 组件（不入 git，随 Release zip 分发）
├─ tests/        # MSTest 测试集
└─ publish/      # 便携交付包（zip，不入 git）
```

## 常见问题

- **Q：拖入后图标是默认文件夹图标？**
  A：表示该文件提取关联图标失败（个别绿色加密/自定义扩展名）。可右键「设置自定义图标…」指定任意 png/ico。

- **Q：`.lnk` 快捷方式打开之后图标是快捷方式的？**（`A`）不会，会自动解析成目标程序图标再提取。

- **Q：便签不怕丢？** 内容写入 `notes.txt`，掉电不丢；Markdown 源码即所见。

- **Q：为什么双击打不开？** 检查是否只运行了单实例（重复启动只会唤起已有窗口）；如仍是打开即消失，看程序目录 `launcher.log` 的错误信息。

- **Q：如何换主题？** 标题栏「🌓」按钮 / `Ctrl+Shift+T` / 设置面板，三者等价。

- **Q：全盘搜索没结果？**
  A：设置 → 常规 → 点「检测」看状态。「索引为空」= Everything 后台还在建索引（首次约几秒到几分钟，看盘大小）；「未运行」= 点一下搜索让它自动拉起；「不可用（原因）」= 按提示处理（最常见是手工删了 `everything\` 目录，重新解压便携包即可）。

- **Q：不想要全盘搜索 / 担心隐私？**
  A：设置面板关掉「Everything 全盘搜索」即可，或直接删除 `everything\` 目录——搜索退化为纯本机图标匹配，其余功能不受影响。Everything 只检索文件名、索引仅存本机。
